# XAI IoT demo

Simple Streamlit demo for the presentation: detect manipulated sensor data, then explain what would make it Normal.

```powershell
cd C:\Users\Hp\Desktop\xai_demo
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

Opens at http://localhost:8501

1. Choose **Manipulated** (91.5°C) for Slide 13.
2. Screenshot the prediction + sample output.
3. Copy Accuracy / Precision / Recall / F1 onto Slide 14.
4. Switch to **Normal** to show the contrast.
